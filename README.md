# Recuperación PHP

App para practicar el examen de recuperación de PHP. Tiene las mismas tres partes que el examen:

- **Test (2 pts):** preguntas a/b/c/d con su explicación. Guarda tus fallos para repasarlos.
- **Corregir errores (2 pts):** marcas las líneas que tienen un error y escribes la corrección.
- **Completar código (4 pts):** huecos que rellenar, y ejercicios «De memoria» en los que escribes líneas enteras (conexión con mysqli, consultas, formularios).
- **Simulacro:** un examen completo con cronómetro y nota sobre 8.
- **Chuleta:** resumen de la sintaxis y de los errores típicos.

Temario: variables y tipos, constantes, condicionales, bucles, formularios GET/POST, `$_FILES`, XAMPP, mysqli y MVC.

## Uso

Abre `index.html` en el navegador, o usa la versión web en GitHub Pages. No necesita instalación ni conexión a internet, y el progreso se guarda en el navegador.
